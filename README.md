# AI Study Skills — Transition Year

A ten-hour practical course hub. Sessions 1–7 currently have full lesson pages.

- Sessions 1–4: prompting, study tools, Wordwall and Educaplay.
- Session 5: Padlet Arcade independent lesson, school-email/password registration, a local prompt builder, checking and peer testing, and an access fallback.
- Session 6: build and publish a first website with GitHub Copilot and GitHub Pages (formerly Session 5).
- Session 7: audit and improve the website (formerly Session 6).
- Sessions 8–9: reserved for further project work; Session 10: sharing and reflection.

The Portfolio tab contains copyable Word templates for Sessions 1–7. Students continue using the same saved Word document.

Static files: `index.html`, `styles.css`, `script.js`. No build step is required. The new prompt builder does not call an AI API or transmit input. The external Padlet service requires its own account to create games.
